Creates a heavily stripped down Version of Windows 11

1.Mount Windows 11 iso using Windows Explorer

2.Extract the downloaded contents into C:\Micro 11 Barebones

3.Open PowerShell as Administrator

4.Copy PowerShell Script Instructions

5.Paste them in PowerShell and press enter and then press y

6.Now enter the mounted drive letter for the Windows 11 image (example F or G)

7.Now enter the image index (example 1 or 2)

8.Thats it all done, after few minutes Micro 11 Barebones.iso will be generated in the folder Micro 11 Barebones

Hope you enjoy this release and feel free to improve the PowerShell script
