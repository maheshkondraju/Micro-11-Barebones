Creates a heavily stripped down Version of Windows 11
Mount Windows 11 iso using Windows Explorer
Extract the downloaded contents into C:\Micro 11 Barebones
Open PowerShell as Administrator
Copy PowerShell Script Instructions
Paste them in PowerShell and press enter and then press y
Now enter the mounted drive letter for the Windows 11 image (example F or G)
Now enter the image index (example 1 or 2)
Thats it all done, after few minutes Micro 11 Barebones.iso will be generated in the folder Micro 11 Barebones
Hope you enjoy this release and feel free to improve the PowerShell script
